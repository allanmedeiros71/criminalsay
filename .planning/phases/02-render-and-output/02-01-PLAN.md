## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compile-time → binary | Embedded quotes.json baked in at build; render formats trusted Quote struct fields only |
| render → stdout | Formatted string crosses to terminal; quote text comes from curated embedded data, not user input |
| lipgloss → ANSI output | When colorEnabled=true, lipgloss emits escape sequences to stdout |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Spoofing | Quote text with embedded terminal control sequences | low | accept | Quote data is curated JSON under source control; no runtime user input. v1 trusted-data model unchanged from Phase 1. |
| T-02-02 | Tampering | lipgloss style output manipulation via malformed Quote fields | low | accept | Fields are compile-time embedded; render concatenates strings without eval. |
| T-02-03 | Denial of Service | Panic on empty quotes slice in main | medium | mitigate | Preserve Phase 1 len(qs)==0 guard before quotes.Random — do not remove during stub replacement (Task 3). |
| T-02-04 | Information Disclosure | ANSI sequences leak terminal capabilities | low | accept | Standard terminal styling; no secrets in output. |
| T-02-05 | Elevation | lipgloss/x/term transitive deps supply chain | low | accept | Packages verified in RESEARCH.md Package Legitimacy Audit (OK verdict); pinned via go.sum. No new direct dependencies beyond lipgloss already in go.mod. |
| T-02-SC | Tampering | lipgloss v1.1.0 module integrity | low | accept | Pre-declared in Phase 1 go.mod; sum.golang.org checksum in go.sum. Go module proxy pinning. |

**Security summary:** Stateless offline CLI. No auth, network, or user input surface. ASVS Level 1 satisfied. One mitigated risk (T-02-03) carried forward from Phase 1 — preserve empty-slice guard in Task 3 main.go wiring.
