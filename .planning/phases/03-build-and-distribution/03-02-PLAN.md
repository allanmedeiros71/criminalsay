| docs → VCS | Documentation is source-controlled; no secrets in README content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-06 | Spoofing | Stale GitHub Releases install instructions pointing to untrusted downloads | high | mitigate | Remove Pre-built binaries / Releases section from README.md (D-08); do not document Releases in README.pt.md |
| T-03-07 | Spoofing | scripts/build.sh reference implies non-existent helper users might fetch elsewhere | medium | mitigate | Remove scripts/build.sh from project structure tree (D-01); document Makefile-only build path |
| T-03-08 | Tampering | Doc drift — README documents make all before Makefile exists | medium | mitigate | 03-02 depends on 03-01; verification task confirms make all works and table matches dist/ |
| T-03-09 | Information Disclosure | Incorrect Go version causes user to run unsupported toolchain | low | mitigate | State Go 1.22+ in both READMEs aligned with go.mod (D-06) |
| T-03-10 | Denial of Service | User follows removed build.sh path and fails | low | mitigate | README.pt.md documents `make` and `go build` only (D-08) |

**Security summary:** Documentation phase has no runtime attack surface. ASVS Level 1 satisfied by removing untrusted download channel references (Releases) until v2 pipeline exists (D-08) and ensuring install instructions point only to `go install` and verified source build. One high-severity threat (T-03-06) mitigated by Releases section removal — block if Releases references remain in either README.
