**As a** developer running CriminalSay for the first time, **I want to** type `./criminalsay` and see a real Criminal Minds quote printed to stdout, **so that** I know the data layer is wired end-to-end before any styling work begins.

Deliver a working binary — the Walking Skeleton — that loads an embedded JSON dataset, selects one quote at random, and prints it unformatted to stdout. This is the thinnest end-to-end path: JSON data → go:embed → quotes.Load() → quotes.Random() → fmt.Println().

</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compile-time → binary | `data/quotes.json` is baked into the binary at build time; no filesystem access at runtime |
| binary → stdout | Output is deterministic quote text; no user-controlled content reaches the output path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `data/quotes.json` (compile-time) | low | accept | Data is compiled into the binary; runtime modification is impossible. At compile time, the file is under source control — standard git integrity. No runtime risk. |
| T-01-02 | Denial of Service | `quotes.Random()` panics when `rand.IntN(0)` called on empty slice | medium | mitigate | `main.go` must check `len(qs) == 0` before calling `Random(qs)` and exit with code 1 + stderr message. Test `TestLoad/empty_array` verifies Load returns empty slice without error, confirming the guard path is reachable. |
| T-01-03 | Tampering | `go.mod` / `go.sum` supply chain (lipgloss v1.1.0 added to module graph) | low | accept | lipgloss v1.1.0 is verified on Go module proxy (sum.golang.org); listed as OK in RESEARCH.md Package Legitimacy Audit. go.sum provides cryptographic pinning of the module graph. Standard Go module security. |
| T-01-04 | Information Disclosure | Embedded binary contains full `data/quotes.json` text | low | accept | Quotes are public domain or published lines from a TV series — no private data. Binary inspection revealing quote text is not a security concern. |
| T-01-SC | Tampering | `go get github.com/charmbracelet/lipgloss@v1.1.0` install step | low | accept | Package verified via `go list -m -json` against Go module proxy (RESEARCH.md); version pinned in go.sum after `go mod tidy`. slopcheck not applicable to Go ecosystem (npm/pip/cargo only per RESEARCH.md Package Legitimacy Audit note). |

**Security summary:** This is a stateless, offline, print-and-exit CLI tool. It reads only compile-time embedded data (no user input, no network I/O, no filesystem access at runtime). The attack surface is minimal. ASVS Level 1 is satisfied: no auth surface, no session management, no network calls, no user-controlled input. The one mitigated risk (T-01-02) is handled by an explicit length guard in main.go.
</threat_model>
