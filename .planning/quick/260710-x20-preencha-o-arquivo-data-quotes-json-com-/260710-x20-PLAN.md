Use WebFetch to gather Criminal Minds episode quotes from fan wikis, IMDB, and dedicated Criminal Minds quote sites. Search season by season to maximize coverage across all 15 seasons.

SCHEMA (enforce on every entry):
- "quote": string — the exact literary/spoken quote text as heard on screen
- "author": string — real-world person who wrote or said it (use character name only if it is original show dialogue with no real-world source)
- "character": string — the BAU agent who delivered it on screen (Aaron Hotchner, Spencer Reid, Derek Morgan, Jennifer Jareau, David Rossi, Emily Prentiss, Jason Gideon, Penelope Garcia, Elle Greenaway, Alex Blake, Kate Callahan, Tara Lewis, Luke Alvez, Matt Simmons, or other cast members)
- "season": integer
- "episode": integer (episode number within the season)
- "episodeTitle": string — the episode title

SEARCH STRATEGY — run these WebFetch calls in sequence, extracting all quotes found:

1. Search for Criminal Minds quotes on these resources:
   - https://criminalmindsfanwiki.com (episode guides with opening/closing quotes)
   - https://www.imdb.com/title/tt0452046/quotes (IMDB quotes page for Criminal Minds)
   - Search "Criminal Minds season 1 episode quotes opening closing" on general web
   - Search each season from 1-15: "Criminal Minds season N quotes wiki"

2. For each season, try to gather 10-20 quotes (each episode typically has an opening AND closing quote). Priority order for gaps:
   - Seasons 1-4 (classic BAU team, high quality quotes)
   - Seasons 5-8 (transition period)
   - Seasons 9-12 (Rossi era peak)
   - Seasons 13-15 (newer cast)

3. Useful URLs to fetch:
   - https://criminalmindsfanwiki.com/wiki/Season_1
   - https://criminalmindsfanwiki.com/wiki/Season_2
   - https://criminalmindsfanwiki.com/wiki/Season_3
   - https://criminalmindsfanwiki.com/wiki/Season_4
   - https://criminalmindsfanwiki.com/wiki/Season_5
   - https://www.quotes.net/mquotes.php?s=criminal+minds (general quotes search)
   - https://en.wikiquote.org/wiki/Criminal_Minds
   - https://www.goodreads.com/work/quotes/... (for specific literary quotes used on the show)

4. DEDUPLICATION: Before adding any quote, check it against the existing 116 entries in data/quotes.json. The following quotes already exist (sample — check full file):
   - "Whoever fights monsters should see to it that in the process he does not become a monster..." (Nietzsche, S1E1)
   - "The belief in a supernatural source of evil..." (Conrad, S1E22)
   - "Out of suffering have emerged the strongest souls..." (Gibran, S2E15)
   - "We are all broken, that's how the light gets in." (Hemingway, S2E22)
   - etc. — load the full file and deduplicate by comparing the "quote" field text

5. After collecting all new quotes, merge them with the existing 116 entries into a single valid JSON array sorted by season then episode.

6. Target: at least 200 new entries added (bringing total to 300+). If web sources yield more, include all verified entries up to ~500.

QUALITY RULES:
- Only include quotes that actually appeared in Criminal Minds episodes (not invented)
- If a quote's author is a real literary/historical figure, use their real name (not "Unknown")
- Do not include quotes where you cannot identify the author — skip them rather than guess
- Character names must match the exact spelling used in the show
- episodeTitle must be the actual episode title, not a description

After all searches are complete and entries are collected, write the merged, deduplicated, sorted array to data/quotes.json using the Write tool.
